## Original creators

**GML Publishing LLC** — author, product design, and the editorial method Translate automates: the repeated Editor → Reviewer → Editor(apply) round that this whole application exists to run at book scale. The prompt design, the bilingual `[N]` payload format that keeps paragraph alignment across a translation pass, and the round/finalize workflow are the author's.

Built for members of the **Future Fiction Academy**.

## Borrowed designs and data

**ModelRouter** (`openrouter-show/openrouter_tk.py`) — the model browser's entire design is a deliberate replica of this Tcl/Tk desktop app: the Tier and Sort dropdowns and their exact option sets, the cumulative price tiers, the sortable **Model | Writing | Context | $ In / Out** table, the `#c0152f` red for thinking models, the compact `128k` / per-million price formats, and the description pane. Credit for that interface belongs to its author; Translate's ModelPicker is a port of it into React, not an independent design.

**EQ-Bench Creative Writing benchmark** — the Writing column. `client/src/data/eqbench_scores.json` (102 models, Elo + rubric) comes from that benchmark via ModelRouter's `update_eqbench.py`, joined to OpenRouter slugs.

**OpenRouter** — the model catalog and the metered API path (`openrouter.ai/api/v1`). Model metadata, pricing, and descriptions in the picker are theirs.

## AI provider tooling

Translate drives these agents over the **Agent Client Protocol**; it does not reimplement any of them:

- **Claude Code** (Anthropic) via `@agentclientprotocol/claude-agent-acp`
- **Codex** (OpenAI) via `@zed-industries/codex-acp` — Zed Industries' adapter
- **Gemini CLI** (Google) via its `--experimental-acp` mode
- **Qwen Code** via its `--acp` mode

The ACP specification and the Python `agent-client-protocol` SDK make the whole subscription-routing approach possible.
